# SteamFilter graphical assets

`ApprovedFaceplate.jpg` is the approved maritime, engraved brass-and-ivory SteamFilter design, used intact as the visual foundation for the editor. The module knob surfaces are not inert controls: `KnobMain.png` and `KnobMini.png` are transparent art layers overlaid by live JUCE rotary indicators, parameter attachments, and drag input. `GaugeFace.png` similarly has a live DSP-load needle. Waveform, sibilance/click/breath/plosive markers, gain traces, module processing meters, and stereo output meter are redrawn live by JUCE.

This preserves the approved design at original 1672 × 941 resolution while allowing controls to update and be automated. Graphical precision should be checked in Cubase at 100%, 125%, and 150% scaling.
